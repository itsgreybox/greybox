Why not just paste the code into Claude or ChatGPT?

Scale. A real legacy system is thousands of files. Nobody pastes those in one at a time — greybox automates the traversal.
Consistency. Every module gets the same structured output, so 200 findings are comparable, not 200 different ad-hoc chat replies.
Cross-file reasoning. Understanding what a system does means knowing Module A calls Module B which reads a config three files away — a single pasted-in file can't see that. greybox builds the real dependency graph first.
Honest uncertainty. The confidence score is computed from real code signals before any AI runs — so the tool can't be talked into a confident-sounding guess.

What this is not (on purpose)

No code rewriting. No migration execution. No full roadmap generation — that's real, valuable work best left to specialist firms. greybox is the fast, cheap first look you'd want before that conversation, not a replacement for it.
