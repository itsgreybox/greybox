Why not just paste the code into Claude or ChatGPT?

Tested this directly: ran greybox against Uber's real public rides-java-sdk — 84 files, not a toy example.

Honest concession first. On 3 files, raw Claude is just as good, maybe better — richer prose, no argument. The gap only shows up at real scale.
At 84 files, "just ask Claude" means 84 separate chat answers in 84 message bubbles, each one prose. To find the riskiest files, you'd have to manually re-read all 84 and rank them yourself — nothing sorts them for you.
greybox gives one ranked list instead. One command, walks away, comes back with every one of the 84 files sorted lowest-confidence-first — "here are the 6 riskiest, go look at those" is one line of output, not an hour of reading.
Structured, not prose. Output is real JSON — diffable against next month's run after a refactor, or wired into a CI check. A chat transcript can't be diffed or gated on.

"But you're just calling Claude API — anyone can do that"

True, and worth saying plainly: yes, anyone can call the Claude API. So does almost every AI product that exists. The real question is whether someone would actually build everything around that API call themselves.

What's actually built, right now

Not a wishlist — every item below is real, tested code, not a roadmap slide.

Python and Java support — auto-detected from the folder, real AST parsers for both (not regex), verified against Uber's public rides-java-sdk (84 files).
JSON export (--format json) — structured, sortable, diffable output for dashboards or CI checks. A chat transcript can't be either.
Concurrent analysis (--workers 8) — 84 files run in parallel instead of one at a time, since each is a network wait, not CPU work.
Secret redaction — hardcoded API keys, AWS keys, passwords, and DB connection strings are stripped before anything is sent to the AI. First pass, not a full secrets scanner — see SECURITY.md.
Suggested next steps per finding — a direct, rule-based answer to "what do I do about this," not a roadmap. See the Top Risks section above.

What this is not (on purpose)

No code rewriting. No migration execution. No full roadmap generation — that's real, valuable work best left to specialist firms. greybox is the fast, cheap first look you'd want before that conversation, not a replacement for it.
