Your code, your machine

Keep it where it already lives

The live scanner reads public repositories only. Most real legacy code is private, and some industries cannot send code to a third party at all. That is what the open-source CLI is for.

Runs locally

Private GitHub, GitLab, Bitbucket, or code that never lived in a hosted repo. Nothing is uploaded by default.

AI is optional

The AI explanation only runs if you set your own API key. Skip it and you still get the dependency graph and confidence scores.

Whole portfolios

Point --portfolio at a folder of repos. Each subfolder gets a full scan, ranked into quick wins, bigger efforts and lower priority.

greybox /path/to/org-repos --portfolio --output portfolio_report.md
